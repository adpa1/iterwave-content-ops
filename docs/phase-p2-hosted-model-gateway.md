# P2：托管模型服务与跨安装实例指标方案

## 结论

当前版本继续采用 BYOK（用户自带模型服务与 API Key）。不启用平台代付模型调用，也不把用户内容发送到未经明确授权的集中式服务。

快速体验目前需要用户先配置模型 Key。托管模型可以缩短首次价值时间，但会把产品从本地/自托管工具变成承担模型费用、数据处理责任和滥用风险的在线服务。缺少运营主体、预算和隐私条款时，不能只靠增加一个 API 地址就上线。

## 目标架构

```text
IterWave 客户端
    |
    | 仅携带短期会话凭证、租户标识、请求幂等键
    v
托管模型网关
    |-- 身份与租户校验
    |-- 配额 / 速率限制 / 风险策略
    |-- 成本预估与硬预算闸门
    |-- 请求审计（不记录明文密钥）
    v
模型供应商适配层（OpenAI 兼容接口）
    |
    v
模型供应商
```

客户端不得持有平台模型密钥。BYOK 和 Hosted 必须是两个明确的计费模式，不能在 BYOK 失败时静默切换到平台付费通道。

## 上线前必须具备

### 1. 成本和配额

- 每租户每日体验次数、每轮模型调用次数、输入/输出 Token 上限。
- 每日、每月平台总预算硬上限；预算耗尽立即拒绝新请求，不允许继续透支。
- 按供应商、模型、Token 数、价格快照、租户、请求 ID 记录用量。
- 失败、超时、重试均按实际供应商用量记账；不能按 HTTP 请求数简单计费。
- 供应商价格变化后保留历史价格快照，支持核算真实毛利。

### 2. 安全与滥用控制

- 租户认证、IP/设备速率限制、并发限制、异常批量请求检测。
- 幂等键、防重放、请求体大小限制、超时和最大重试次数。
- API Key 只保存在服务端密钥管理系统，日志和客户端响应不得出现明文。
- 平台设置全局熔断开关，可立即关闭 Hosted，BYOK 继续可用。

### 3. 数据与隐私

- 在用户发起 Hosted 请求前明确告知：账号定位、选题和生成所需文本会发送给模型供应商。
- 明确数据处理主体、供应商名单、处理地区、保存期限、删除机制和是否用于模型训练。
- 默认不持久化完整 Prompt / Response；必要审计只保存请求 ID、模型、Token、时延、错误码和脱敏元数据。
- 提供用户主动删除体验记录及相关服务端缓存的流程。
- 禁止把账号 Cookie、平台登录态、API Key、个人敏感信息放入模型请求。

### 4. 可靠性

- 供应商适配器、模型路由、超时、限流和熔断配置化。
- 供应商错误码映射为稳定业务错误码。
- 仅对可重试错误执行有上限的重试；不重复扣费。
- 记录模型和提示词版本，支持质量回归与成本对照。

## P2 验收门槛

| 领域 | 验收标准 |
|---|---|
| 密钥 | 客户端、日志、数据库均无供应商明文密钥 |
| 预算 | 租户限额与全局预算均为服务端硬闸门 |
| 计费 | Token 用量、价格快照、失败重试和实际成本可对账 |
| 隔离 | 租户之间不能读取彼此的用量、内容和任务 |
| 隐私 | 用户同意、数据地区、留存期限和删除机制有正式文档 |
| 滥用 | 限流、异常检测、封禁和全局关闭开关可用 |
| 回退 | Hosted 故障不会静默切换到其他付费通道 |
| 质量 | 与 BYOK 同一套正式质量门；模型输出不能绕过 G2 |

## 跨安装实例 TTV P50/P90

当前激活 Cohort 存在各自账号组数据库中。本版本已经输出当前数据库内可观察 Cohort 的 TTV P50/P90，并明确返回样本数和统计范围；这不是跨独立安装实例的总体分位数。

真正的跨安装实例统计需要独立、可选加入的匿名聚合遥测服务：
- 只上传随机安装标识、首次激活时间、首次价值时间、耗时分段、产品版本和统计所需的最少字段。
- 不上传账号定位、生成内容、Prompt、平台账号、Cookie、API Key 或用户身份信息。
- 用户可以退出遥测；退出后本地激活功能不受影响。
- 服务端按统计周期计算 P50/P90，样本不足 5 个独立安装时不展示总体分位数。
- 遥测原始事件设置短留存期，聚合结果不反向识别单个安装。

该遥测服务与 Hosted 模型网关可以共用身份/租户基础设施，但必须分别授权、分别开关，不能将“使用 Hosted”视为默认同意遥测。

## 需要产品负责人作出的决策

在开始实现前，必须明确：
1. 谁承担模型费用与在线服务运营责任。
2. 每月预算上限及单用户体验成本上限。
3. 采用哪家模型供应商、部署地区和数据处理条款。
4. 是否允许匿名遥测，默认加入还是默认退出。
5. 是否接受 Hosted 仅限体验样稿，不覆盖正式生产。

以上决策未明确前，Hosted 保持关闭，BYOK 是唯一可用模式。
